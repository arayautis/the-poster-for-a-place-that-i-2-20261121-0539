A travel poster for **Velmora**, a place that does not exist: three floating
isles at dusk, their waterfalls falling up into the sky, a lighthouse
keeping watch over a calm sea. The poster is painted pixel by pixel by
`main.py` using only the Python standard library — no images, no fonts on
disk, no network — so the same run always writes the same poster.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (768 x 1024, well under the 1 MiB limit).
